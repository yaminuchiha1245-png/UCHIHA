# UCHIHA Builder Changelog

## 2026-07-30 — Store account, security, external support and catalog API

- إضافة واجهة حساب موحّدة للهاتف تشمل المحفظة، إضافة الرصيد، دفعاتي، طلباتي،
  الدعم الخارجي، ربط Telegram، الحماية، توثيق الهوية، API ومن نحن.
- إضافة هيدر ديناميكي يعرض صورة الحساب والرصيد والإشعارات، وشريط سفلي ثابت
  بالترتيب المعتمد: السلة، طلباتي، الرئيسية، المحفظة، الحماية.
- إضافة سلة محلية آمنة مع شراء متعدد العناصر من المحفظة وإعادة تحقق كاملة في Backend.
- إضافة TOTP حقيقي مع تحدي تسجيل دخول، Recovery Codes، إدارة الجلسات وسجل أمان.
- إضافة أكواد ربط Telegram قصيرة العمر ومخزنة كـHash مع منع ربط الحساب بأكثر من عميل.
- إضافة تدفق توثيق هوية اختياري، تشفير رقم الوثيقة ومحتوى الصور، ملفات خاصة،
  مراجعة إدارية، حالات وملاحظات وسجل أحداث.
- إضافة API قراءة خاص بالأقسام والمنتجات فقط، ومفاتيح مخزنة كـHash، صلاحيات،
  Rate Limit، IP Allowlist، إلغاء وإعادة توليد ودليل أمثلة.
- إضافة إعدادات تجربة لكل متجر وقنوات دعم خارجية قابلة للإدارة دون تثبيت هوية UCHIHA.
- إضافة شاشة إدارة ويب للحساب والحماية وقنوات الدعم ومراجعة توثيق الهوية.
- إضافة حذف آلي لملفات الهوية والبيانات الحساسة بعد مدة الاحتفاظ الخاصة بكل متجر.
- توسيع Ledger بعمليات ورصيد قبل/بعد وعمولات، وتطوير قوائم الدفعات والطلبات وتفاصيلها.
- إضافة Migrations 018–019 وسياسات RLS لجميع الجداول الجديدة.

## 2026-07-29 — Unified platform and category-first commerce

- إضافة نموذج المشاريع والخدمات والمكوّنات لتجميع الموقع والبوتات وتطبيقات الهاتف
  فوق API وقاعدة بيانات موحّدتين.
- تحويل إنشاء المتجر إلى معالج من 7 خطوات مع حفظ المسودة واختيار مكوّنات المشروع.
- تبسيط لوحة صاحب المتجر إلى ستة مداخل أساسية وتجميع الأدوات المتقدمة في مركز
  إعدادات واضح.
- منع تحميل منتجات الواجهة الرئيسية واعتماد الأقسام الرئيسية ثم الفرعية مع
  Pagination وبحث خادمي عند الحاجة فقط.
- إضافة بانر صورة أو GIF أو فيديو متكرر، وشريط معلومات متحرك بسلاسة.
- إضافة دعم داخلي كامل ومحادثات للعميل وصندوق رد للمالك.
- إضافة مستوى ولاء وطلبات العميل ودفعاته وإشعاراته داخل المحفظة.
- إضافة عملات عرض موثقة السعر، مع منع تفعيل تحويل غير صالح أو غير مؤرخ.
- إضافة PWA ومشروعي Android وiOS وهوية Native أصلية، وبناء APK تجريبي كـArtifact
  في GitHub Actions.

## 2026-07-28 — Atomic wallet order refunds

- إضافة إلغاء آمن لطلبات المحفظة مع إعادة الرصيد مرة واحدة فقط.
- ربط Refund بـIdempotency وRow Locks وLedger وAudit والإشعارات وOutbox.
- منع الاسترداد التلقائي بعد إرسال الطلب إلى المزود، وعدم إعادة المخزون تلقائيًا للخدمات الرقمية.
- تشديد تحديث طرق الدفع بإضافة `tenant_id` إلى شرط التحديث.
- تغطية إعادة المحاولة بالمفتاح نفسه، وتغيير البيانات، ومحاولة الاسترداد الثاني باختبارات End-to-End.
