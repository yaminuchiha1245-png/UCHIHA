# UCHIHA Builder Changelog

## 2026-07-28 — Deterministic product intelligence

- إضافة محلل قواعد حتمي لحقول شراء المنتجات دون استدعاء AI أثناء عملية الشراء.
- تخزين نتيجة التحليل وإصدار المحلل ودرجة الثقة داخل قاعدة البيانات.
- تطبيق تلقائي للمنتجات الواضحة وإرسال النتائج الغامضة إلى Review Queue.
- إضافة تحليل دفعات وواجهة مراجعة واعتماد أو تجاهل المقترحات.
- إضافة Migrations 009–010 وسياسات RLS واختبارات العزل والتطبيق.

## 2026-07-28 — Wallet and financial administration

- فصل جلسات عملاء المتاجر باستخدام Cookie خاصة بكل Store.
- إضافة Idempotency مرتبطة بالعميل ومحتوى الطلب لطلبات الإيداع والشراء.
- إضافة التحقق من توقيع صور إثبات التحويل وحجمها ونوعها.
- جعل قبول الإيداع وشراء المحفظة وتعديل الرصيد معاملات ذرية مع Row Locks.
- إضافة إشعارات العملاء وملاك المتاجر وسجل Audit وأحداث Outbox.
- إضافة إدارة طرق الدفع والعملاء والأرصدة والطلبات من لوحة مالية متجاوبة.
- إضافة Pagination وبحث وتصفية للعملاء والطلبات والسجل المالي.
- منع إلغاء الطلب المدفوع من واجهة الحالة قبل توفير Refund مستقل.
- إضافة Migrations 005–008 وسياسات RLS للجداول المالية الجديدة.
- إضافة اختبارات إعادة المحاولة والعزل ومنع الخصم أو الإضافة المتكررة.
- الاحتفاظ بمخرجات الاختبارات كـArtifact في GitHub Actions لتسريع تشخيص أي فشل.


## 2026-07-28 — Storefront scale, templates and request protection

- اعتماد ثلاثة قوالب أساسية مع توافق تلقائي مع أسماء القوالب القديمة.
- إضافة محرر تصميم ومعاينة مباشرة داخل لوحة الإدارة.
- إضافة بحث وPagination للمنتجات في الإدارة والمتجر العام.
- إضافة فهارس PostgreSQL للكتالوج والطلبات وطابور التحليل.
- إضافة Rate Limiting للتسجيل والدخول والشراء والإيداع.
- فرض روابط HTTPS للشعارات والأغلفة وصور الأقسام والمنتجات المخصصة.
- إضافة قائمة تجهيز Staging مستقلة دون تنفيذ النشر.
