## عمل محلي لم يكتمل

- [ ] مطابقة الواجهة الأصلية والتحقق من مسارات الدخول والأزرار على الهاتف.
- [ ] تحسين الواجهة والأيقونات في الدفعة الأخيرة فقط.

## بوابات تحتاج بيئة أو حسابات خارجية

- [ ] إنشاء OAuth Client رسمي وضبط `GOOGLE_CLIENT_ID`.
- [ ] اختيار مزود الدفع وربط المحول الحقيقي واختبار النجاح والفشل والإلغاء والاسترداد، أو اعتماد إجراء المراجعة اليدوية رسميًا.
- [ ] إنشاء بوت Telegram وضبط token وwebhook HTTPS.
- [ ] PostgreSQL مُدار مع نسخ احتياطي واستعادة مجربة.
- [ ] نطاق HTTPS وشهادة وWAF/مراقبة.
- [ ] مختبر FreeRADIUS + MikroTik محدود الصلاحيات واختبار فصل/إعادة اتصال.
- [ ] تشغيل workflow أندرويد بشهادة الإنتاج والتحقق من AAB على أجهزة حقيقية وحساب Play Console.
- [ ] سياسة خصوصية وشروط استخدام وبيانات جهة الدعم.
- [ ] تجربة تجريبية مع مزود واحد وبيانات غير حساسة ثم قبول مكتوب.

## أمر القبول المحلي

```bash
npm run release:check
```

يمكن تشغيل المسار المحلي نفسه مباشرةً باستخدام `node scripts/verify-local.mjs`. النتيجة الآلية في `docs/verification/latest-local-check.json`؛ نجاحها لا يعني تشغيل اختبار PostgreSQL المتجاوز أو تجربة Google والشبكة الفعلية.

لا يُوصف الإصدار بأنه إطلاق عام قبل إغلاق جميع البوابات الخارجية أعلاه.
