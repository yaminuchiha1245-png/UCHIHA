# مرجع التصميم المحفوظ

`UCHIHA-RADIUS-UI-V1-11.html` نسخة محفوظة دون تعديل من العمل السابق. هذا ملف عرض تجريبي وليس واجهة إنتاج متصلة بالخادم.

لا يُستبدل المرجع بمعاينة `apps/provider-web` المختلفة. أثناء إكمال الربط يجب نقل الوظائف إلى التصميم الأصلي بحذر، دون خسارة الميزات الموجودة أو إنشاء مشروع بديل. يوضح `docs/release-status.md` الفجوة الحالية والعمل المتبقي.
