# UCHIHA Store

> المصدر التشغيلي الحالي للمتجر هو فرع `main`.

منصة متجر رقمية عربية متكاملة، مهيأة للجوال وPWA، وتشمل:

- بوت متجر Telegram مبني على aiogram.
- بوت إدارة المنصة والمستأجرين.
- واجهة عميل داكنة RTL بتسجيل دخول وإنشاء حساب.
- واجهة متجر ويب تقرأ المنتجات الحقيقية فقط من قاعدة JS4Card المشتركة.
- تنفيذ طلبات JS4Card مباشرة من الخادم مع منع الخصم أو الطلب المكرر.
- رصيد وطلبات موحدة بين الموقع وبوت Uchiha.
- ربط تلقائي آمن مع البوت عبر رابط Telegram لمرة واحدة وصلاحية 10 دقائق.
- لوحة إدارة خاصة بصاحب المتجر على `/admin`.
- تحكم بصور السلايدر والأقسام وترتيبها وبيانات الدعم والألوان.
- إدارة العملاء والأرصدة والطلبات وطلبات الشحن وطرق الدفع.
- طريقتا Binance منفصلتان: Pay ID وUSDT-TRC20.
- مركز Sham Cash مستقل وجاهز للربط الرسمي عند توفر توثيق الحركات.

## الصفحات

- `/` أو `/shop`: تطبيق العميل.
- `/admin`: لوحة صاحب المتجر.
- `/v1/storefront/health`: فحص الجاهزية.

## التكاملات

### JS4Card

تكامل الخادم هو المصدر الوحيد للتعامل مع API Token، ولا يصل الرمز إلى المتصفح. يدعم الكتالوج والشراء وخيارات المنتجات ودقة الأسعار ومنع الطلب المكرر.

### Binance

يدعم:

- Binance Pay ID.
- USDT TRC20 (TRON).
- Transaction ID / TXID.
- التحقق من العقد والمبلغ والعنوان والوقت.
- منع إضافة الرصيد مرتين.
- مراجعة يدوية آمنة عند تعذر Binance Pay API.

راجع `BINANCE_SETUP.md` لإعداد المتغيرات.

### Sham Cash

المركز الإداري موجود، لكن الاعتماد التلقائي يجب أن يبقى مغلقًا حتى توفر توثيق رسمي للحركات وإجراء اختبار حي.

## التشغيل

```bash
pip install -r requirements.txt
python storefront_launcher.py
```

## الاختبارات

```bash
python -m unittest tests/test_binance_compat.py
python -m unittest tests/test_storefront_core.py
python -m unittest tests/test_shamcash_admin.py
python tests/binance_integration_smoke.py
python -m compileall -q .
```

## قاعدة الأمان

لا تحفظ مفاتيح API أو ملفات `.env` الحقيقية أو كلمات المرور أو أسرار الإنتاج داخل GitHub.
