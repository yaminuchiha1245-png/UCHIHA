# UCHIHA — لوحة إدارة تطبيق الديون عبر بوت Telegram

بوت مستقل عن بوت Game Zone، متصل بقاعدة بيانات تطبيق الديون نفسها.
لا يعيد بناء تطبيق Android ولا ينقل أرصدة المستخدمين إلى قاعدة منفصلة.

## لوحة الأزرار

- 💰 الأرصدة: بحث باسم العميل أو هاتفه، إضافة/خصم بالمبلغ والسبب وتأكيد ثانٍ.
- 👥 المستخدمون: عرض الرصيد، الأجهزة، حالة الاشتراك، تفعيل/إيقاف، إعادة ضبط الأجهزة.
- 🎟 الأكواد: إنشاء أكواد (اسم، هاتف، عدد أجهزة، تاريخ انتهاء) واسترجاع كود عميل.
- 🏦 طلبات الشحن: مراجعة الإثبات، قبول المبلغ أو تعديله، رفض مع سبب.
- 🛒 الطلبات: حالات المنتجات الرقمية مع ملاحظة إدارية. تغيير الحالة لا يلغي طلب
  المزوّد ولا يعيد الرصيد تلقائيًا.
- 📜 سجل الأرصدة، 🗂 سجل الإدارة، ⚙️ الإعدادات وفحص الاتصال.

**الرصيد هنا رصيد محفظة المنتجات الرقمية، وليس ديون الزبائن داخل دفتر المحل.**

## الإعداد على VPS

أولًا: تأكد أن ترحيل قاعدة البيانات في sql/001_telegram_admin.sql مطبّق
على مشروع تطبيق الديون. هذا الترحيل قد ثُبّت على مشروع Supabase المعتمد
jmluqclcwwuldwhaspgz. إذا كنت تستعمل مشروعًا آخر، نفّذه هناك مرة واحدة.

انسخ محتويات مجلد bot إلى مسار آمن على السيرفر (مثال
/opt/uchiha/debt-admin)، وشغّل من داخل المجلد:

~~~bash
python3 setup.py
~~~

سيسألك الإعداد عن توكن البوت من @BotFather، ورقم Telegram ID لحساب
المدير الوحيد، وعنوان Supabase (القيم الافتراضية جاهزة)، ثم مفتاح
service_role مرة واحدة لإنشاء اعتماد خاص للبوت. **مفتاح service_role لا
يُحفظ في البوت**، وينشئ البرنامج مفتاح ربط مستقل بطول 256 بت.

يمكنك الحصول على رقم حسابك بإرسال /myid إلى @userinfobot. لا ترسل
توكن البوت ولا مفاتيح Supabase في محادثات Telegram أو ChatGPT.

ثم شغّل:

~~~bash
python3 bot.py
~~~

افتح بوتك بحساب المدير وأرسل /start. يعمل في المحادثات الخاصة فقط
ومن Telegram ID المحدد، ويمكن لأي شخص استخدام /id لمعرفة رقمه هو فقط.

لتشغيل دائم، انسخ ملف bot/uchiha-debt-admin.service إلى systemd بعد تعديل
المستخدم والمسار حسب VPS:

~~~bash
sudo systemctl daemon-reload
sudo systemctl enable --now uchiha-debt-admin.service
sudo systemctl status uchiha-debt-admin.service
~~~

المتطلبات: Python 3.10+ فقط؛ مكتباته القياسية كافية.

## الحماية

- كل حركة رصيد تحتاج تأكيدًا، وتحمل معرّفًا فريدًا ثابتًا يمنع ازدواج
  الإضافة/الخصم حتى إن انقطع الاتصال وأعيد الطلب.
- الأكواد لا تُعاد تلقائيًا عند نتيجة اتصال مجهولة؛ راجع قائمة المستخدمين.
- منع مراجعة طلبات الشحن مرة ثانية مفروض من قاعدة البيانات.
- bot.sqlite3 يحفظ حالة الأزرار والطلبات الإدارية فقط، وليس أرصدة
  المستخدمين باعتبارها مصدر الحقيقة؛ الأرصدة الفعلية في Supabase.
- bot/.env يحتوي فقط مفاتيح البوت الخاصة، وصلاحياته للمالك؛ لا ترفعه
  إلى GitHub. استخدم setup.py لتغيير التوكن بأمان.
- إعداد البوت لا يستهلك جهاز تفعيل من حساب مالك Android.

الحالي ولا تثبت APK جديدًا لأجل هذا البوت. جرّب قبول شحن مبلغ صغير
ومراجعته داخل التطبيق قبل تعميم استخدام لوحة الإدارة.
